| 梅花楷 | `MeiHuaKai.ttf` |
| 后现代体 | `HouXianDai.otf` |
| 思源中宋 | `NotoSerifSC-Medium.otf` |
| 若烟体 | `RuoYan.ttf` |
| 甜甜圈 | `TianTianQuan.ttf` |
| 快乐体 | `KuaiLeTi.ttf` |
| 晴雪体 | `QingXue.ttf` |
| 梦槐体 | `MengHuai.ttf` |

有正版字体时覆盖同名文件即可。拉取开源思源中宋：

```bash
python scripts/fetch_overlay_fonts.py
```
